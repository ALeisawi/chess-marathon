# Chess Marathon

A mobile chess runner. Start as a pawn and run 1000 ranks while black answers every move and the board collapses behind you.

Play it: open `index.html` in a phone browser, or enable GitHub Pages for this repo.

- Tap a highlighted square to move. Red marks are squares black can take.
- Capture a piece to become it. A pawn on a gold rank becomes a queen.
- Capture on back-to-back moves for combos.
- Settings (gear icon): sound, vibration and shake, pop-up messages.
- Four themes: Classic wood, Cartoon, Neon arcade, Minimal flat.
